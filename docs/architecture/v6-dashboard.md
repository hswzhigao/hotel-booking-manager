# V6 设计 — 仪表盘重构（总账 / 详情弹窗 / 收益图表）

状态：**Finalized**（2026-09-21 用户反馈）

## 1. 需求
- 酒店/高尔夫**分账之上要有总账**（合并合计）
- 「最近预定」点击不再跳预定管理页，改为**就地弹详情**；酒店/高尔夫分开列表也可合并查看
- 新增**收益图表**：按日/周/月/年 × 酒店/高尔夫/全部，展示收益趋势

## 2. 后端

### stats/summary 扩展（合并总账字段）
- 新增：`all_order_count / all_total_sale / all_total_cost / all_total_profit / all_month_sale / all_month_profit`（酒店+高尔夫合并，口径同分账：酒店排除 cancelled+communicating、高尔夫排除 cancelled）
- 既有 hotel_* / golf_* / today_*（today 已是合并）/ channels 保留

### 新接口 GET /api/stats/trend
- 参数：`bucket=day|week|month|year`（默认 day），`limit`（day 默认 30、week 12、month 12、year 3，上限 90）
- 返回：`{ items: [{ period, hotel_sale, hotel_cost, golf_sale, golf_cost }] }` 按周期正序
  - period 形态：day→'2026-09-21'；week→'2026-W38'；month→'2026-09'；year→'2026'
  - 归期字段：order_time；口径与 summary 一致
  - 前端自行求和（all = hotel+golf）与利润，一次拉取可切换业务线
- 实现：SQL 按日期格式分组（DATE_FORMAT %Y-%m-%d / %x-W%v / %Y-%m / %Y），酒店+高尔夫 UNION 后聚合，补齐无数据周期由前端处理（图表 gap）

## 3. 前端（DashboardView 重构）

### 布局（自上而下）
1. **总账卡组**（第一行）：总收益 / 总成本 / 总利润 / 今日收益 / 本月收益（酒店+高尔夫合并，大数字）
2. **分账卡组**：酒店业务（订单/收入/成本/利润/本月）与高尔夫业务（订单/收入/成本/利润/本月）两区块并排（移动端上下堆叠）
3. **收益趋势图卡**（echarts，按需引入 LineChart/BarChart）：
   - 控件行：维度按钮组（按日/按周/按月/按年）+ 业务按钮组（全部/酒店/高尔夫）+ 指标切换（收入/利润）
   - 图：柱状+折线混合或纯折线（收入柱、利润线），tooltip 显示周期内酒店/高尔夫明细
   - 无数据周期补 0 展示
4. **最近订单卡**：tab 切换「酒店预定 / 高尔夫订单」，行点击 → **就地只读详情 Dialog**（不再跳转）；「查看全部」仍跳对应列表页

### 详情 Dialog（Dashboard 内置只读组件，两种）
- 酒店单：状态徽标+流程步数、客户/酒店/入住~离店(晚)、明细（房型×每晚价×小计）、卖价/成本/利润、权益（种类张数/预订人）、双早/渠道/结算、下单时间
- 高尔夫单：状态、客户/球场/日期/人数、权益种类/预订人、卖价/成本/利润、教定位/渠道、下单时间

### 移动端
- 卡组堆叠、图表容器 100% 宽（高度 260px）可横向拖动查看长周期、tab 与按钮组自适应换行

## 4. 依赖
- 新增 `echarts`（按需注册组件控制体积；图表为刚需，超出 V1「不用额外组件库」限定，本设计明示豁免）

## 5. 验收场景
1. 总账 = 酒店分账 + 高尔夫分账（API 与 UI 双核对）
2. trend：造跨周期数据（近3天两单），day/week 切换 period 正确、无数据补零、明细与 summary 一致
3. 图表：维度/业务/指标切换即时刷新；tooltip 含分线数字
4. 最近订单：酒店/高尔夫 tab 数据正确；行点击弹对应详情，字段齐全；不再发生路由跳转
5. 移动端 375px：无横向滚动（图表容器内滚动除外）、卡组堆叠正常、控制台零错误
6. 桌面回归：其余页面不受影响
